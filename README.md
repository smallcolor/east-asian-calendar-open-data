# East Asian Calendar & Solar Terms Open Data (2020-2035)

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24500394.svg)](https://doi.org/10.5281/zenodo.24500394)

Deterministic JSON and CSV reference datasets for East and Southeast Asian calendrical systems, published by [Koyomi Days](https://koyomidays.com/en/open-data/) under [CC BY 4.0](LICENSE).

- English Open Data Portal: https://koyomidays.com/en/open-data/
- 日本語オープンデータ: https://koyomidays.com/ja/open-data/
- 繁體中文開放資料: https://koyomidays.com/zh-hant/open-data/
- Zenodo Archive (DOI): https://doi.org/10.5281/zenodo.24500394
- Kaggle Dataset Mirror: https://www.kaggle.com/datasets/koyomidays/east-asian-calendar-open-data-2020-2035

## Datasets

| File | Range | Rows | Timezone / Rule | Description |
|---|---|---:|---|---|
| `data/solar-terms-2020-2035.json` / `.csv` | 2020-2035 | 384 | UTC, JST (`UTC+9`), CST (`UTC+8`) | 24 solar terms (`SOLAR_RULE` VSOP87D) at exact minute precision |
| `data/lunar-new-moons-2020-2035.json` / `.csv` | 2020-2035 | 198 | CST (`UTC+8`) | Civil new moon days (`朔日`, lunar day 1) under `lunar-hko/2` |
| `data/lunar-new-year-cross-tz-2020-2035.json` / `.csv` | 2020-2035 | 16 | `UTC+8` / `UTC+7` / `UTC+9` | Cross-timezone Lunar New Year comparison for China, Vietnam, and Korea |
| `data/jp-almanac-2025-2030.json` / `.csv` | 2025-2030 | 2,191 | JST (`UTC+9`) | Daily Sexagenary pillars, Rokuyo, Ichiryumanbaibi, Tenshabi, Tora-no-hi, Minohi (`巳`), and Doyo windows |
| `data/ko-son-eomneun-nal-2025-2030.json` / `.csv` | 2025-2030 | 409 | KST (`UTC+9`) | Korean Son-eomneun-nal (`손 없는 날`) dates where lunar day ends in 9 or 0 |
| `data/id-javanese-pasaran-2025-2030.json` / `.csv` | 2025-2030 | 2,191 | Civil date (`JDN`) | Deterministic 5-day Pasaran (`Legi`, `Pahing`, `Pon`, `Wage`, `Kliwon`), Weton, and Neptu |

## Quickstarts

### Python (Pandas)

```python
import pandas as pd

terms = pd.read_csv("data/solar-terms-2020-2035.csv")
lichun = terms[terms["term_slug"] == "lichun"][["year", "utc_iso", "jst_iso", "cst_iso"]]
print(lichun.head())

lny = pd.read_csv("data/lunar-new-year-cross-tz-2020-2035.csv")
print(lny[lny["differs_cn_vn"] | lny["differs_cn_kr"]])
```

### JavaScript / Node.js (`@koyomidays/solar-terms`)

A zero-dependency ESM package is included in [`packages/solar-terms/`](packages/solar-terms/):

```js
import { getSolarTerms, getSolarTerm, getSolarTermOnDate } from './packages/solar-terms/index.js';

const terms2026 = getSolarTerms(2026);
const lichun2026 = getSolarTerm(2026, 'lichun');
const onDate = getSolarTermOnDate('2026-02-04', 'jst');
console.log(lichun2026.jst_iso, onDate?.term_en);
```

Run the package test suite:

```bash
cd packages/solar-terms && node test.mjs
```

## VSOP87D Accuracy & Rule Verification

1. **Solar Terms (`solar_rule`: VSOP87D)**: Solar longitude crossings (multiples of 15 degrees) are solved deterministically using truncated VSOP87D series (`src/core/vsop87d.js` and `src/core/astro.js`), converted to civil instants rounded to the nearest minute in UTC, JST (`+09:00`), and CST (`+08:00`).
2. **China & Korea/Japan Lunar Tables**:
   - China (`UTC+8`): `lunar-hko/2` (`src/core/lunar.js`), aligned with Hong Kong Observatory conversion tables.
   - Korea & Japan (`UTC+9`): `lunar-jst/1` (`src/core-ext/lunar-jst.js`), derived from local-midnight new moon and principal solar term rules in `UTC+9`.
   - Vietnam (`UTC+7`): `vn-lunar.js` for 2026-2030 and `astronomy-engine 2.1.19` (`engine/lunar_engine.py`) at `UTC+7` for 2020-2025 and 2031-2035. Independent astronomical calculation; unverified against an official Vietnamese almanac.
3. **Japanese Almanac (`almanac/1`, `rokuyo/1`)**: Rokuyo (`(lunar_month + lunar_day) % 6` in JST), Ichiryumanbaibi, Tenshabi, Tora-no-hi (`寅`), Minohi (`巳`), and Doyo entry/window boundaries (`27°`, `117°`, `207°`, `297°` through the day before `立夏`/`立秋`/`立冬`/`立春`) are computed from `src/core/almanac.js` and `src/core-ext/rokuyo.js`.
4. **Javanese Pasaran**: Computed deterministically from the Julian Day Number (`JDN mod 5` for Pasaran, `(JDN + 1) mod 7` for weekday) and traditional Javanese Neptu weights.
5. **Reproducibility**: All files in `data/` are generated by [`scripts/generate.mjs`](scripts/generate.mjs).

## 日本語サマリー

本リポジトリは、Koyomi Days（[https://koyomidays.com/ja/open-data/](https://koyomidays.com/ja/open-data/)）が公開する東アジア・東南アジア暦法の検証済みオープンデータセット（CC BY 4.0）です。VSOP87D による二十四節気（2020-2035 年・UTC/JST/UTC+8 分単位）、旧暦朔日、中越韓の旧正月対照表、日本の暦注データ（2025-2030 年：六曜・一粒万倍日・天赦日・寅の日・巳の日・土用期間）、韓国のソンオムヌンナル、ジャワ暦のパサラン周期を JSON・CSV 形式で収録しています。

## 繁體中文摘要

本儲存庫為 Koyomi Days（[https://koyomidays.com/zh-hant/open-data/](https://koyomidays.com/zh-hant/open-data/)）發布的東亞與東南亞曆法開放資料集（CC BY 4.0）。資料皆由確定性天文與曆法演算法產生，包含 2020-2035 年二十四節氣（VSOP87D 精確至分鐘，含 UTC、JST、UTC+8）、朔日表、中越韓三時區農曆新年對照、2025-2030 年日本曆注（六曜、一粒萬倍日、天赦日、寅日、巳日、土用區間）、韓國無損日與爪哇五日循環週期，提供 JSON 與 CSV 格式。
